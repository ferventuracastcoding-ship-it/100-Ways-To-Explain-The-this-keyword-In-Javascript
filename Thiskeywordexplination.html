JavaScript "this" Keyword

10 Different Examples with Explanations + Canvas Animation

1. Global Context

In the global scope, this refers to the global object (window in browsers). 

console.log(this);

2. Object Method

Inside an object method, this refers to that object. 

const person = {
    name: "Alice",
    greet(){
        console.log(this.name);
    }
};

person.greet();

3. Constructor Function

When using new, this refers to the newly created object. 

function Car(model){
    this.model = model;
}

const c = new Car("Tesla");
console.log(c.model);

4. Class Example

Inside a class, this refers to the class instance. 

class Dog{
    constructor(name){
        this.name = name;
    }

    bark(){
        console.log(this.name);
    }
}

5. Arrow Function

Arrow functions do not create their own this. They inherit it from the surrounding scope. 

const obj={
    value:10,

    show(){
        const arrow=()=>{
            console.log(this.value);
        };
        arrow();
    }
};

6. Regular Function

Regular functions have their own this depending on how they are called. 

function hello(){
    console.log(this);
}

7. Event Listener

Inside an event handler, this refers to the clicked element. 

button.onclick=function(){
    console.log(this);
};

8. call()

call() lets you manually set this. 

function greet(){
    console.log(this.name);
}

greet.call({name:"John"});

9. apply()

apply() is similar to call(), but arguments are passed as an array. 

function add(a,b){
    console.log(this.name,a+b);
}

add.apply({name:"Math"},[5,7]);

10. bind()

bind() creates a new function with this permanently attached. 

const user={
    name:"Sarah"
};

function sayHi(){
    console.log(this.name);
}

const hi=sayHi.bind(user);
hi();
